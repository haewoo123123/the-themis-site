WINDOWS

PC에 설치하기

  1. Windows 버튼으로 설치 파일을 받아 실행
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행
  3. 바탕화면의 The Themis로 시작
ANDROID

휴대폰에 설치하기

  1. Android 버튼으로 APK를 받아 열기
  2. "출처를 알 수 없는 앱" 안내가 뜨면 설정 → 이 출처 허용
  3. 설치 후 가로로 들고 플레이
WEB

바로 플레이하기

  1. 웹에서 플레이를 누르면 브라우저에서 바로 시작
  2. 진행은 그 브라우저에 저장돼요
  3. 기기를 옮길 땐 설정 → 데이터에서 코드로 전송
